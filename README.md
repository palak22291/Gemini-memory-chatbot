# Gemini Memory Chatbot

A simple AI chatbot built using the Gemini API that supports conversation memory.

## Features

- Gemini API integration
- Interactive command-line chat
- Conversation memory using chat history
- Context-aware responses

## Tech Stack

- Python
- Google Gemini API
- python-dotenv

## Concepts Learned

- LLM API integration
- Context management
- Memory systems
- Token usage tradeoffs

## Future Improvements
